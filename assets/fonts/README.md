Static TTFs for the link-preview cards (`components/og/SocialCard.tsx`). `next/og` cannot read the WOFF2 files that `next/font` serves, so the cards load these at build time.

- Plus Jakarta Sans ExtraBold (800), by Tokotype
- JetBrains Mono SemiBold (600), by JetBrains

Both come from Google Fonts and are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
